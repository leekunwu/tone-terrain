# Tone Terrain

Spotify CSV 데이터를 불러와 앨범과 곡의 오디오 특성을 시각화하는 브라우저 앱입니다.

## 실행

압축을 푼 뒤 `index.html`을 브라우저에서 엽니다. 파일과 폴더의 상대 위치를 유지하세요. GitHub Pages에서도 정적 파일로 제공할 수 있습니다.

## 파일 구성

- `index.html`: 화면 구조와 스크립트 로드 순서
- `styles.css`: 공통 및 화면 스타일
- `assets/suit-variable.woff2`: 원본에 내장된 폰트
- `js/state.js`: 공통 상수와 상태
- `js/csv.js`, `js/data.js`: CSV 읽기와 데이터 그룹화
- `js/map.js`: 지도 투영, 렌더링과 조작
- `js/panel.js`: 상세·비교 패널 렌더링
- `js/import.js`, `js/project.js`: 가져오기와 프로젝트 저장·복원
- `js/events.js`: 버튼 등 UI 이벤트 및 초기 렌더링

JavaScript는 기존 전역 상태를 공유하는 일반 스크립트이며 로드 순서를 유지해야 합니다. UI 수정 사항은 아래 변경 내역을 참고하세요. 외부 패키지나 빌드 도구는 필요하지 않습니다.

## 데이터 관리

가져온 데이터는 브라우저 메모리에서 처리됩니다. 실제 CSV 및 프로젝트 JSON은 개인정보와 업무 데이터 포함 여부를 확인한 뒤 저장소에 추가하세요. 폰트 재배포 조건을 확인한 후 공개 저장소에 게시하세요.

## 이번 변경
- 육각형 축 이름과 수치를 두 줄로 분리하고 차트 여백 확대.
- 호버 제목과 차트를 블록으로 분리, 화면 경계 안으로 위치 보정.
- 확대 모달 진입 및 닫기/Esc 시 호버 팝업 숨김. 원래 차트를 벗어난 뒤 재진입하면 다시 표시.
- SVG 내부 이동에 따른 팝업 깜박임 방지. 스크롤·리사이즈·패널 갱신 시 숨김.
- 트랙 Spotify 원형 버튼 28px → 22px.
- 기본 강조색 #E6496C, 다크 모드 #FF6B8A 적용.

## 검증 및 수동 QA
전체 JS 문법 검사와 모의 이벤트 기반 팝업 상태 전환 검사를 통과했습니다.
현재 환경의 브라우저 실행 제한으로 실제 화면 검증은 미완료입니다.
- 앨범·곡·비교 차트에서 긴 제목, 0/100/결측 수치가 겹치거나 잘리지 않는지 확인.
- 호버 → 클릭 → 닫기/Esc 후 팝업이 숨겨지고, 벗어났다가 재진입하면 다시 표시되는지 확인.
- Tab/Enter/Space 키보드 조작과 좁은 화면, 라이트·다크 모드 확인.
- CSV 반영, 검색, 비교, Spotify 링크 확인.

## 적용 및 롤백
수정 파일: styles.css, js/panel.js, js/events.js, README.md.
기존 파일을 백업한 뒤 교체하세요. 문제 발생 시 위 파일을 이전 버전으로 복원합니다.
데이터 처리와 저장 형식은 변경하지 않았습니다. 외부 의존성은 추가하지 않았습니다.
이 앱은 정적 브라우저 앱이며, Apps Script 프로젝트에 직접 clasp push하는 대상이 아닙니다.
