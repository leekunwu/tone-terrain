# Tone Terrain

Spotify CSV 데이터를 불러와 앨범과 곡의 오디오 특성을 시각화하는 브라우저 앱입니다.

## 실행

압축을 푼 뒤 `index.html`을 브라우저에서 엽니다. 파일과 폴더의 상대 위치를 유지하세요. GitHub Pages에서도 정적 파일로 제공할 수 있습니다.

## 사용 방법

1. Spotify에서 분석할 곡을 담은 **공개 플레이리스트**를 만들고 링크를 복사합니다.
2. [Chosic Playlist Exporter](https://www.chosic.com/spotify-playlist-exporter/)에서 링크를 붙여넣고 Analyze 후 **CSV를 다운로드**합니다.
3. CSV를 Tone Terrain에 넣습니다(파일 추가 또는 지도 위에 끌어놓기).

## 기능

- 앨범/곡 보기, X·Y·Z 축 선택, 검색, 비교(앨범·곡 섞어서 최대 3개), 깃발 플래그와 "플래그만 보기". 플래그한 항목은 앨범·곡 뷰 어디서나 지도에서 박동(심장 뛰듯 번지는 링)으로 표시되고, GRID ON/OFF로 그 항목을 지나는 X·Y·Z 축선을 켜고 끕니다.
- **유사도 구**: 선택한 앨범/곡을 중심으로 현재 X·Y·Z 축 거리 기준의 구를 만들고, 슬라이더(유사도 하한)로 반경을 조절해 구 안의 목록을 봅니다. 유사도 = `100 × (1 − 거리 / 2√3)` (정규화 좌표 -1~1 기준, 계산은 `js/sphere.js`).
- Spotify 재생: 목록·상세의 ▶ 버튼을 누르면 지도 왼쪽 아래 플레이어(Spotify 임베드 iframe 하나를 재사용)에서 바로 재생되고, 목록이 있으면 끝날 때 다음 곡으로 넘어갑니다. 임베드 주소는 CSV의 트랙 ID로 만듭니다(`open.spotify.com/embed/track/{ID}`). 로그인하지 않으면 30초 이내 미리듣기만 나오고, 미리듣기가 없는 곡은 10초 뒤 건너뜁니다. 재생 중인 점은 곡의 BPM 그대로의 주기로, Energy에 비례한 세기로 초록색으로 발광·박동하며 재생 위치에 맞춰 위상이 보정됩니다(실제 소리 크기는 교차 출처 iframe이라 측정할 수 없어 메타데이터로 표현). 재생 중인 곡의 목록 행에는 초록 테두리가 표시됩니다. 스페이스바로 재생·일시정지합니다(입력창·선택창·버튼에 포커스가 있을 때는 기본 동작 유지, 재생 전이면 선택한 곡 재생).
- 자동 회전: 헤더의 회전 버튼이 누를 때마다 X축 → Y축 → Z축 → 전체 → 정지 순으로 바뀝니다(데이터 축 기준 회전, 전체는 회전축이 천천히 떠돌며 모든 면을 보여줌). 첫 화면에서는 안내문 뒤로 3D가 흐리게 천천히 돌고, 파일을 넣으면 회전이 멈추고 기본 시점으로 부드럽게 돌아옵니다("중앙 정렬" 버튼도 같은 동작).
- 지도 조작: 드래그 회전, 휠 확대, Ctrl·Cmd·Shift+드래그 또는 우클릭 드래그로 위치 이동(Shift+방향키도 가능).
- 오른쪽 패널: 경계를 끌어 폭 조절(더블클릭으로 초기화, 폭은 localStorage에 저장). 선택 항목은 위쪽에 고정되고 스크롤하면 작게 접힙니다.
- 처음에는 오른쪽 패널이 숨겨져 있고, CSV를 불러오면 부드럽게 열리며 전체 초기화하면 다시 닫힙니다.
- CSV 세트별 색: 파일(세트)마다 점 색이 다릅니다. 첫 세트는 회색, 이어서 보라, 갈색, 올리브, 슬레이트, 모브 순으로 채도를 낮춘 색을 쓰고(6개 넘으면 반복), 세트가 둘 이상이면 지도 왼쪽 위에 범례를 보여줍니다. 앨범은 첫 수록곡의 파일 색을 따릅니다. 비교·플래그·선택 색은 그대로 우선합니다.
- 도움말: "도움말" 버튼(또는 시작 화면의 "사용법 둘러보기")이 5단계 온보딩을 엽니다(이전/다음, 방향키, 단계 점).
- 제목 "Tone Terrain"을 누르면 전체 초기화(확인창 표시). 프로젝트 JSON에 데이터·선택·비교·플래그·구가 저장됩니다.

## 파일 구성

- `index.html`: 화면 구조와 스크립트 로드 순서
- `styles.css`: 공통 및 화면 스타일
- `assets/suit-variable.woff2`: 원본에 내장된 폰트
- `js/state.js`: 공통 상수, 초기 상태(`A0`), 사용 가이드 문구
- `js/csv.js`, `js/data.js`: CSV 읽기, 데이터 그룹화, 보이는 항목 필터(`vis`)
- `js/sphere.js`: 유사도 구 계산(순수 함수)
- `js/rot.js`: 자동 회전용 사원수 계산(순수 함수)
- `js/help.js`: 5단계 온보딩(도움말) 대화상자
- `js/player.js`: Spotify 임베드 플레이어, 다음 곡 이동, 박동 계산
- `js/map.js`: 지도 투영, 렌더링과 조작
- `js/panel.js`: 상세·비교·플래그·구 패널 렌더링
- `js/import.js`, `js/project.js`: 가져오기와 프로젝트 저장·복원, 전체 초기화
- `js/events.js`: 버튼 등 UI 이벤트, 패널 폭 조절, 초기 렌더링
- `test/sphere.test.js`, `test/rot.test.js`, `test/player.test.js`: 유사도·회전·플레이어 로직 테스트

JavaScript는 기존 전역 상태를 공유하는 일반 스크립트이며 로드 순서를 유지해야 합니다. 외부 패키지나 빌드 도구는 필요하지 않습니다.

node test/sphere.test.js

## 데이터 관리

가져온 데이터는 브라우저 메모리에서 처리됩니다. 실제 CSV 및 프로젝트 JSON은 개인정보와 업무 데이터 포함 여부를 확인한 뒤 저장소에 추가하세요. 폰트 재배포 조건을 확인한 후 공개 저장소에 게시하세요.

## 검증 및 한계
로컬 정적 서버에서 브라우저로 확인한 항목: CSV 가져오기, 곡·앨범 비교, 플래그, 유사도 구, 패널 폭 조절, 지도 이동(Ctrl+드래그), 제목 초기화, 프로젝트 저장·복원, 라이트/다크, 데스크톱·모바일(375px) 폭.
확인하지 못한 항목: 60fps 실기기에서의 회전·박동 체감, 실제 Mac의 Cmd+드래그·우클릭 드래그, 터치 기기 조작, Safari·Firefox, 수천 곡 규모의 성능.
- 구 반경은 중심점 기준 원으로 근사해 가장자리에서 원근 오차가 있을 수 있습니다.
- 유사도는 현재 X·Y·Z 3축 거리 기준이며 축을 바꾸면 결과도 바뀝니다.
- 플래그는 한 종류(깃발)이고 프로젝트 JSON으로만 보관됩니다(자동 저장 없음).
